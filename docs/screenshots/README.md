# Screenshot pengumpulan

Tugas meminta bukti screenshot tahap pengerjaan (setup PostgreSQL, migrasi, dan seed), serta tampilan desktop dan mobile. Folder ini disiapkan untuk bukti tersebut.

Setelah menjalankan aplikasi dan database lokal:

1. Simpan tangkapan layar terminal setelah migrasi dan seed berhasil di sini.
2. Simpan screenshot aplikasi pada browser desktop di sini.
3. Simpan screenshot responsive mobile dari DevTools browser di sini.
4. Cantumkan semua gambar tersebut di README root sebelum pengumpulan.

Screenshot proses database belum dapat direkam di workspace ini karena PostgreSQL dan kredensial database lokal tidak tersedia. Jangan gunakan screenshot contoh sebagai bukti proses aktual.
